# Astra artwork

- `AstraIcon-v3-1024.png` is the selected 1024 px source artwork.
- `Astra.icns` is the macOS icon copied into release bundles.
- `AstraIcon-v2-1024.png` is retained as the previous design reference.

The artwork uses Astra's single muted-indigo accent (`#6669B7`) on a neutral
pure-black surface and contains no text, gradients outside the app tile, or
additional brand colors.
